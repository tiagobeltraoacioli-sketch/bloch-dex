# Postern visual standard

Version 1 — September 8, 2026.

Postern DEX is the visual reference for this rollout. Its established graphite and lime palette is retained, with a 16px body baseline, medium-weight h1 headings, and a 10px surface radius token. All 29 frontend tests and the production build pass. Contract code, balances, routing, and wallet integration are unchanged.

The canonical palette and design guidance are in `bloch-sis-pow/docs/site/BRAND-KIT.md` and `docs/site/assets/bloch-tokens.css`. The approved institutional website is maintained in `bloch-sis-pow/apps/site/`.

These source changes retain the existing release process. Production deployment is separate from the design update.
