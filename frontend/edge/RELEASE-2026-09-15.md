Reproduce with Node 24 from `frontend/`:

```sh
npm test
npm run build
npm run build:native-page
POSTERN_PREVIEW_PAGE=1 POSTERN_NATIVE_PAGE=1 \
POSTERN_RECOVERY_ARTIFACT=edge/recovery-2026-09-14.json npm run build:mobile-hotfix
node --test edge/preview.check.mjs
```

`POSTERN_PREVIEW_PAGE=1` to cover the complete preview and its menu link.
